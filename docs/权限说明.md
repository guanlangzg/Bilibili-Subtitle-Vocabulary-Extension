# 权限说明

Bilibili Subtitle Vocabulary 遵循最小权限原则，仅请求实现功能所必需的权限。本文档与 `manifest.json` 保持同步，任何权限变更都会在 Release Notes 中明示。

## 权限清单

### 必需权限（permissions）

| 权限 | 用途 |
|---|---|
| `activeTab` | 读取当前标签页域名，判断当前站点授权状态 |
| `scripting` | 在用户授权的页面注入字幕替换与 Overlay 脚本 |
| `storage` | 保存设置、生词本、复习队列和学习指标到 `chrome.storage.local` |

### 默认主机权限（host_permissions）

| 主机 | 用途 |
|---|---|
| `https://www.bilibili.com/*` | 在 Bilibili 视频页注入字幕替换与 Overlay |
| `https://api.bilibili.com/*` | 请求 Bilibili 官方播放器和字幕 API |
| `https://aisubtitle.hdslb.com/*` | 请求 Bilibili AI 字幕 API |
| `https://www.youtube.com/*` | 在 YouTube 视频页注入字幕替换与 Overlay |

### Optional Host 权限（optional_host_permissions）

| 主机 | 用途 |
|---|---|
| `"*://*/*"` | 用户主动授权后，在非默认站点启用网页正文词汇替换模式；也可用于用户自建的同步服务器 |

## 内容脚本注入范围

默认内容脚本只运行在以下两个站点：

- `"https://www.bilibili.com/*"`
- `"https://www.youtube.com/*"`

不会自动运行在所有 `http://*/*` 或 `https://*/*` 页面。对于非默认站点，扩展需要通过 `optional_host_permissions` 在用户主动点击的授权按钮后，才会请求对应主机权限；拒绝授权后不启用当前站点。

## 权限使用边界

### 不会做的事

- 不采集浏览历史、不追踪用户行为
- 除用户在选项页自行配置并主动触发同步的服务器外，不上传学习数据到任何远程服务器
- 不调用远程翻译服务，所有翻译基于本地词库
- 不注入广告、不引入第三方分析 SDK
- 不请求 `tabs`、`webRequest`、`history`、`bookmarks` 等敏感权限

### 可选主机权限的触发

`optional_host_permissions: *://*/*` 仅在以下场景使用：

1. 用户在 Popup 中点击「授权当前站点」
2. 用户在 Options 站点管理中主动添加非默认站点规则
3. 用户在 Options「学习记录同步」保存服务器地址或点击「立即同步」时，按该服务器源（协议 + 主机）单独申请
4. 浏览器会弹出原生授权确认框，用户可随时撤销；拒绝授权则不会向该服务器发起请求

### 数据存储

所有用户数据存储在 `chrome.storage.local`，包括：

- 设置配置（profiles、globalControls、siteRules）
- 生词本与复习队列
- 学习事实事件与逐词基线（`bili_vocab_learning_data_v1`）
- 学习指标（连续学习、命中统计、自动调优状态）
- Onboarding 状态
- 同步配置（`bili_vocab_sync_settings_v1`：服务器地址、访问令牌、设备标识、游标与上次同步结果）

数据不会同步到 Chrome 账户（不使用 `storage.sync`）。未配置同步服务器时，数据不会离开本地浏览器；配置并主动同步后，学习事实 bundle 会发送到用户填写的服务器，扩展设置与统计不会随包发送。

## 权限变更政策

任何权限变更都会在 Release Notes 中明确说明，并通过版本号升级体现。用户可在浏览器扩展管理页随时查看和撤销权限。
