# 词库来源与许可证

Bilibili Subtitle Vocabulary 的词库由多个公开数据源构建。本文档说明各数据源的许可证与再分发边界。

## 数据源清单

### 可再分发（MIT）

| 数据源 | 用途 | 许可证 | 再分发 | 署名 |
|---|---|---|---|---|
| [ECDICT](https://github.com/skywind3000/ECDICT) | 英汉词典，含 CET4/CET6/IELTS/TOEFL/考研标签 | MIT | 允许 | 必须 |
| [Words-CEFR-Dataset](https://github.com/Maximax67/Words-CEFR-Dataset) | CEFR 等级标注 (1-6) | MIT | 允许 | 必须 |
| [《全国大学英语四、六级考试大纲（2016年修订版）》词表](https://github.com/ismartcoding/endict) | CET4/CET6 考纲词目判定与缺失词补齐 | MIT | 允许 | 必须 |

《全国大学英语四、六级考试大纲（2016年修订版）》词表经 [ismartcoding/endict](https://github.com/ismartcoding/endict) 整理，存放于仓库根目录 `cet6-vocabulary/syllabus-2016/`（四级 6127 词 / 六级 1715 词）。构建时：

1. 词表内的词条在对应等级标记 `syllabus` 来源；
2. 词表内但 ECDICT 未打四六级标签的词，用 ECDICT 的释义/音标/词性补齐为词条（避免考纲词缺失）；
3. 词表中的多词短语（`according to`、`ice cream` 等 14 条）不进入单词级词库，因为分词器只匹配单词 token。

考纲词汇来源的分类目录、许可证原文与逐条核验记录见 `cet6-vocabulary/README.md`。

### 需审查（不可直接再分发）

以下数据源在发布包中**不会包含**其派生数据，仅用于本地开发构建：

| 数据源 | 用途 | 状态 | 处理方式 |
|---|---|---|---|
| [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary) | CET4/CET6/考研词表 | 上游已有 BSD 3-Clause 许可证，构建清单记录待更新 | 发布包使用 publish-safe 数据集替代 |
| [exam-data/NETEMVocabulary](https://github.com/exam-data/NETEMVocabulary) | 考研词频排序 | NOASSERTION | 发布包移除 NETEM 派生的排序字段 |

#### KyleBing/english-vocabulary 的许可证现状（2026-10-18 复核）

- 上游仓库根目录存在 `LICENSE`：BSD 3-Clause License，`Copyright (c) 2022-2026, KyleBing`，许可证原文见 `cet6-vocabulary/licenses/kylebing-BSD-3-Clause.txt`。
- 该许可允许带署名再分发，因此 `data/sources.json` 中的「无明确许可证元数据 / needs-review / 阻断发布」记录已过时。
- 但解除阻断会使发布包包含其释义与考试词频字段，并使 publish-safe 构建的 `coverageTier: core` 高频层由空变为有值（产品口径变更），需维护者单独决策；在决策前发布策略维持现状。

## 发布包数据策略

Release 附件中的扩展包使用 **publish-safe 数据集**：

1. 仅包含 MIT 和 CC BY-SA 3.0 许可证下的可再分发数据
2. 移除所有 `needs-review` 状态数据源的派生字段
3. 保留所有必要的署名信息

## 本地开发

克隆仓库后，`bilibili-vocab-extension/sources/` 目录包含原始数据源文件，用于本地构建完整词库。这些文件**不应**被再分发到发布包中。

不可再分发内容的过滤发生在**打包阶段**（`pnpm run pack` 与 `pnpm run release:check`，经 `scripts/pack-extension.js` 调用 `build-vocab-dataset.js --publish-safe` 重建发布数据集）。`pnpm run build:extension` 本身只做 React 构建与产物检查，不处理词库数据；仓库 `data/` 目录此时仍是 development 数据，不可直接分发。

## 署名

本扩展在以下位置保留署名：

- README.md 的「数据与许可证」章节
- 本文档
- Release Notes 中的数据源变更说明
- 发布包内的 `data/ATTRIBUTION.md` 与 `data/sources.json`（随扩展安装产物分发）

## 许可证变更处理

如任何数据源的许可证发生变更，本扩展会：

1. 在 Release Notes 中明确说明
2. 评估对发布包的影响
3. 必要时移除受影响的数据

## 贡献者须知

向词库贡献数据时，请确保：

1. 数据来源明确，附上原始 URL
2. 许可证状态可验证
3. 在 `data/sources.json` 中更新数据源清单
4. 不引入 `needs-review` 状态的数据到发布包
