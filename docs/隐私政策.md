# 隐私政策

Bilibili Subtitle Vocabulary（以下简称「本扩展」）高度重视用户隐私。本政策说明扩展如何处理数据。

## 核心承诺

本扩展是**本地优先、零遥测**的浏览器扩展：

- **无账号**：不需要注册、登录或任何身份信息；可选的同步服务器使用用户自己的访问令牌
- **默认不同步**：未配置同步服务器时，所有数据只存储在本地 `chrome.storage.local`
- **可选的自建服务器同步**：仅当用户在选项页填写服务器地址与访问令牌，并手动点击「立即同步」或「检查服务器状态」时，才会与该服务器通信；扩展不内置、也不默认连接任何项目自有服务器
- **无遥测**：不收集、不上报任何使用数据
- **无广告**：不嵌入任何广告或追踪 SDK
- **无远程翻译**：所有翻译基于本地词库，不调用外部 API

## 数据收集

**本扩展不收集任何用户个人数据。** 可选的同步功能由用户自行部署服务器，数据直接发往该服务器，不经过项目维护者。

## 数据存储

以下数据存储在本地浏览器中，默认不会离开设备（「学习事实」仅在用户主动触发同步时发送到其自建服务器）：

| 数据类别 | 存储键 | 内容 | 用途 |
|---|---|---|---|
| 设置配置 | `bili_vocab_settings_v3` | 配置档、全局开关、站点规则 | 控制扩展行为 |
| 生词本 | `bili_vocab_word_stats_v2` | 收藏的单词、命中统计、复习状态 | 学习闭环 |
| 复习队列 | `bili_vocab_review_queue_v1` | 待复习单词队列 | 间隔复习 |
| 学习指标 | `bili_vocab_learning_summary_v1` | 今日/累计学习统计 | 进度展示 |
| 连续学习 | `bili_vocab_learning_streak_v1` | 连续学习天数 | 进度展示 |
| 自动调优 | `bili_vocab_adaptive_tuning_v1` | 自动调优状态与决策 | 策略优化 |
| 体验指标 | `bili_vocab_experience_metrics_v1` | 误替换反馈、调优执行次数 | 策略优化 |
| Onboarding | `bili_vocab_onboarding_v1` | 引导完成状态 | 首次体验 |
| 学习事实（同步用） | `bili_vocab_learning_data_v1` | 学习事件与逐词基线快照 | 与安卓 App 共用学习记录 |
| 同步配置 | `bili_vocab_sync_settings_v1` | 服务器地址、访问令牌、设备标识、游标与上次结果 | 连接用户自建服务器 |

访问令牌与服务器地址只保存在本机 `chrome.storage.local`，不会发送给除该服务器地址以外的任何一方。

## 网络请求

本扩展仅在以下场景发起网络请求：

### Bilibili 字幕

- 请求 Bilibili 官方播放器和字幕 API 获取字幕时间轴
- 请求目标：`api.bilibili.com`、`aisubtitle.hdslb.com`
- 请求内容：视频 BV 号、字幕索引
- 不包含任何用户身份或学习数据

### YouTube 字幕

- 从 YouTube 页面读取 caption DOM，不发起额外网络请求

### 可选的学习记录同步（用户自建服务器）

只有在用户于选项页「学习记录同步」中保存服务器地址与访问令牌，并主动点击「检查服务器状态」或「立即同步」后，扩展才会向该地址发起请求。没有定时任务或后台自动同步。

- 请求目标：用户填写的服务器地址（`GET /v1/status`、`GET /v1/pull`、`POST /v1/push`）
- 请求头：`Authorization: Bearer <访问令牌>`
- 发送内容：学习事实 bundle，包含学习事件（单词、事件类型、发生时间、时区偏移、本地日期、词书代码、复习评分、调度算法与版本、来源设备 ID）和逐词基线快照；事件的上下文字段可能包含字幕原句、页面标题、页面 URL 与视频时间点；若填写了可选的「设备标识」，该值作为 `clientId` 随请求发送
- 不发送：扩展设置、主题与布局、Onboarding 状态、体验指标、自动调优状态、本地派生的学习统计与连续天数
- 主机权限：扩展只声明可选的全站权限，实际按用户填写的服务器源（协议 + 主机）在点击时单独申请；未授权则不同步
- 同步先拉取并校验远端记录，再合并到本地并上传。标识相同但内容冲突的记录不会覆盖原记录；如果上传失败，已经成功导入的远端记录仍保留在本地，游标不前进

### 不做的事

- 除用户自行配置的同步服务器外，不向任何第三方服务发送数据
- 不调用远程翻译 API
- 不上报崩溃日志或错误信息

## 站点授权

对于非默认站点（非 Bilibili / YouTube），扩展通过显式用户授权 UI 请求主机权限：

1. 用户在 Popup 中点击「授权当前站点」
2. 浏览器弹出原生授权确认框
3. 用户可随时在浏览器扩展管理页撤销授权

## 数据删除

用户可通过以下方式删除数据：

1. **清空生词本**：Options → 数据与备份 → 清空已收藏生词
2. **恢复默认设置**：Options → 数据与备份 → 恢复默认设置
3. **卸载扩展**：浏览器扩展管理页卸载，所有 `chrome.storage.local` 数据会被清除

清空生词本会取消本地收藏；恢复默认设置不删除学习记录。取消收藏的事件可在下次手动同步时上传，但这些操作**不会删除已上传的历史学习事实**。卸载扩展也不会删除服务器上的副本。同步服务器由用户自行管理，服务端数据的删除需要在该服务器上单独操作。扩展只调用 `/v1/status`、`/v1/pull`、`/v1/push`，没有远程删除接口。

## 第三方服务

本扩展不集成任何第三方分析、广告或追踪服务。

## 儿童隐私

本扩展面向一般英语学习者，不专门面向 13 岁以下儿童。不会故意收集儿童个人信息。

## 政策变更

任何隐私政策变更都会通过 Release Notes 和版本号升级明示。继续使用即视为接受更新后的政策。
