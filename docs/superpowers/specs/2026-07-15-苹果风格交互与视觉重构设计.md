# 苹果风格交互与视觉重构设计

## 背景

当前扩展包含 Popup、Options 和 Overlay 三个 React UI 入口，职责划分基本正确，但存在以下体验问题：

- Popup 将站点控制、学习预览、自动调优、字幕导航、快速复习、生词排行和统计等九个面板纵向堆叠，默认高度超过 3000px，首要任务不明确。
- Options 使用大 Hero、状态胶囊和多层卡片组织设置，首屏空间利用率低，视觉层级偏重。
- Overlay 将统计、字幕导航、配置、开关、位置和保存操作全部放在长面板中，容易遮挡视频。
- 现有设计文档使用暖色 “Evidence Warm Precision”，未提交 token 改动又转向冷蓝 “Signal Clarity”，视觉语言不一致。
- Popup 与 Overlay 中存在可以即时提交的轻量设置，但仍展示重复保存动作，增加认知负担。

## 目标

本次重构采用已经确认的 **Apple Utility + 任务优先** 方向：

1. 让三个入口打开后都能立即完成其最主要任务。
2. 将低频能力渐进披露，减少滚动、卡片堆叠和同权信息竞争。
3. 建立中性、克制、系统化的浅色与深色视觉语言。
4. 统一即时保存、显式保存、失败恢复、冲突和撤销体验。
5. 保持现有 Settings V3、存储桥接和业务能力不变，不引入新的 UI 或状态管理依赖。

## 非目标

- 不迁移 React 技术栈。
- 不修改字幕替换、复习算法、词库或后台设置 schema。
- 不新增数据分析、账户、云同步或跨设备能力。
- 不提供自由缩放 Overlay；尺寸继续由 Options 管理。
- 不重构与本次 UI 无关的内容脚本和后台模块。

## 总体设计原则

### 任务优先

- Popup：当前站点、快速复习、字幕导航。
- Options：完整配置、可恢复编辑、冲突处理和维护操作。
- Overlay：观看现场的字幕控制、轻量学习和少量即时设置。

### 渐进披露

- Popup 默认只展示三项主任务，自动调优详情、生词排行、完整统计和显示选项放入“更多控制与学习统计”。
- Overlay 默认展示紧凑控制栏，展开后通过“字幕 / 学习 / 设置”标签页切换。
- Options 使用侧边导航和分组列表，低频与高风险操作集中在“数据与备份”。

### 单一主操作

- 每个视图只保留一个视觉主操作。
- Popup 与 Overlay 的轻量控制即时保存，不展示额外保存按钮。
- Options 保留“保存更改”作为主操作，“撤销”降为次要操作。

## Popup 设计

### 默认结构

Popup 默认宽度维持约 400-440px，高度目标约 650px：

1. 紧凑应用栏：产品标识、当前配置档、自动保存状态、打开设置图标。
2. 当前站点控制：域名、连接状态和站点开关。
3. 三项摘要：待复习、今日新词、连续学习。
4. 快速复习：单张词卡、上下文和“不认识 / 模糊 / 认识”动作。
5. 字幕导航：当前字幕摘要和“上一句 / 重播 / 下一句”。
6. 更多披露：自动调优、生词排行、完整统计、显示模式和授权说明。
7. 底部状态区：仅在保存、错误、冲突或撤销窗口存在时出现。

### 交互规则

- 站点开关、主题、显示模式和自动调优等轻量设置提交明确快照并即时保存。
- 快速复习与字幕导航只禁用当前动作，不锁定整个 Popup。
- 更多区域记住本次 Popup 生命周期内的展开状态，不新增持久化字段。
- 首次引导以紧凑目标选择器替代大面积引导面板；完成或跳过后不占据常规首屏。
- 外部冲突、授权失败或保存错误发生时，自动展开对应恢复入口。

## Options 设计

### 布局

- 保留五个现有分类，但侧边导航只显示图标和短标签，移除每项的长描述。
- 移除大 Hero 和状态胶囊墙。
- 顶部使用紧凑工具栏展示当前分类、配置档、同步状态、撤销和保存。
- 主内容改为系统设置式分组列表：相关控件共享一个表面，通过分隔线组织。
- 配置档和场景预设使用分段选择或紧凑选项组。
- 实时预览只在学习策略等需要判断效果的分类出现，不保持全局悬浮卡片。

### 编辑与保存

- Options 继续维护 `saved` 与 `working` 工作副本。
- 所有编辑先更新工作副本，用户点击“保存更改”后统一提交。
- 未保存状态显示在工具栏，不使用循环脉冲动画。
- 外部更新与本地工作副本冲突时，在内容顶部展示冲突范围和“使用远端 / 保存本地”。
- 恢复默认、删除配置档、删除站点规则和清空收藏仍需确认或 6 秒撤销。

## Overlay 设计

### 紧凑态

默认紧凑态目标尺寸不超过约 360×64px，包含：

- 拖动把手。
- 字幕连接状态和当前配置档。
- 上一句、重播、下一句三个图标按钮。
- 展开、隐藏按钮。

### 展开态

展开态使用三个标签页：

- 字幕：当前字幕、进度和导航。
- 学习：三项摘要、最近词汇和快速复习。
- 设置：配置档、替换比例、主要运行开关和主题。

位置控制不再使用“向左 / 向右 / 上移 / 下移”按钮。用户拖动把手移动面板，松开后将限制在当前视口内并持久化 `offsetRight` 与 `offsetBottom`。

### 保存规则

- Overlay 中开关和选择即时保存。
- 滑杆拖动时只更新预览，停止拖动或键盘操作结束后提交。
- 保存失败时保留本地工作值，显示重试入口，不静默回滚。
- 外部更新在无本地编辑时立即应用；存在本地编辑时保留编辑并提示到 Options 处理冲突。

## 视觉系统

### 色彩

采用中性灰表面与系统蓝主操作：

- 浅色背景接近 `#F5F5F7`，主表面接近白色。
- 深色背景使用中性炭黑与深灰，不使用偏蓝的大面积深色。
- 主操作使用可访问的系统蓝；Bilibili 粉仅用于极少量品牌提示或视频进度，不承担通用操作语义。
- 成功、警告、错误使用语义色，并同时配合图标或文字。

### 字体与层级

- 使用 `-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC` 等系统字体栈。
- 不再使用衬线展示字体和渐变文字。
- 通过字号、字重、间距和分组建立层级，不依赖大量颜色。
- 数据使用等宽数字特性，避免数值更新造成布局抖动。

### 表面与控件

- 页面分区保持无框或使用单层分组表面，避免卡片嵌套。
- 卡片圆角不超过 8px；浮层、模态框和 Popup 外壳可使用 12-16px。
- 阴影只用于浮层、模态框和真正抬升的表面。
- 按钮、输入、开关和图标按钮的点击区域至少 44×44px。
- 动画使用 150-240ms 的透明度或位移过渡，不使用无限脉冲和装饰动画。

## 状态与数据流

### 即时保存

Popup 和 Overlay 的即时保存必须提交事件处理器生成的明确 Settings V3 快照，避免依赖尚未完成的 React 状态更新。

流程如下：

1. 根据当前设置创建并规范化下一份快照。
2. 立即更新界面工作值。
3. 禁用当前控件并提交该快照。
4. 成功后用持久化返回值校准 `saved` 与 `working`。
5. 失败时保留工作值，显示重试并保持 dirty 状态。

普通切换和下拉在单次保存期间禁用当前控件。滑杆允许连续预览，但只在交互结束后提交，避免高频写存储。

### 显式保存

Options 继续复用现有 `useV3Settings` 保存、对账和冲突逻辑。保存期间允许用户继续编辑；持久化完成后保留保存期间产生的新编辑。

### 反馈时序

- 0-300ms：只显示按压或选中状态。
- 超过 300ms：当前控件显示加载状态。
- 成功：局部显示“已保存”，随后恢复常态。
- 失败：持久错误信息包含原因、恢复动作和重试。
- 动态状态使用 `aria-live="polite"`；阻断性错误使用 `assertive`。

## 错误与冲突处理

- 初始读取失败：展示明确错误、建议和重试。
- 即时保存失败：保留用户值，允许重试或放弃本地修改。
- Options 保存失败：保留工作副本，不清除 dirty。
- 外部冲突：显示冲突范围，允许应用远端或保存本地覆盖。
- Overlay 拖动保存失败：面板保持当前位置，本地提示失败；下次成功设置写入时再次持久化。
- 破坏性操作继续使用确认对话框或 6 秒撤销，不新增多步向导。

## 无障碍与响应式

- 图标按钮必须有 `aria-label` 和 Tooltip。
- 键盘焦点顺序与视觉顺序一致，保留高对比 `:focus-visible`。
- Overlay 支持 `Esc` 折叠；标签页使用正确的 `tablist / tab / tabpanel` 语义。
- 支持 `prefers-reduced-motion`，禁用非必要位移和动画。
- 浅色与深色主题分别满足正文 4.5:1、较大图标与边界 3:1 的最低对比度。
- 200% 缩放和窄视口下不得出现文字遮挡或水平滚动。
- Options 在 980px 以下改为单栏内容，在 720px 以下将侧边导航替换为顶部分类选择。

## 测试与验收

### 自动化测试

- 为 Popup 更多区域、即时保存和错误恢复补充组件或契约测试。
- 为 Overlay 标签切换、拖动边界、位置持久化和即时保存补充测试。
- 保留 Options 保存对账、冲突和撤销测试。
- 更新布局契约，锁定三入口职责和关键可访问性属性。

### 工程验证

- `pnpm run lint --fix`
- `pnpm run typecheck`
- `pnpm test`
- `pnpm run build:extension`
- `pnpm run test:ui`

### 浏览器验证

- Popup：420×900 和 375×812，检查默认高度、展开区域、键盘操作和明暗主题。
- Options：1440×900、980×900 和 720×900，检查导航、保存工具栏、缩放和无水平溢出。
- Overlay：在视频夹具中验证紧凑态、展开态、标签页、拖动、视口边界、隐藏恢复和明暗主题。
- 启用减少动态效果后截图并检查无必要动画。
- 检查控制台错误、页面错误和不可见焦点。

## 成功标准

- Popup 默认内容高度约 650px，三个主要任务无需展开即可完成。
- Options 首屏直接进入设置内容，不再由 Hero 和状态胶囊占据主要空间。
- Overlay 紧凑态不超过约 360×64px，展开后不再使用单一长滚动面板。
- Popup 与 Overlay 不再展示重复保存按钮。
- 三入口使用同一套 Apple Utility token、控件和状态反馈语言。
- 所有现有业务能力仍可从符合职责的入口访问。
- lint、类型检查、单测、构建、UI 测试和浏览器视觉检查全部通过。
